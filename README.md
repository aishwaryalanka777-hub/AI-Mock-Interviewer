# 🎤 AI Mock Interviewer

An AI-powered mock interview platform built using Python and Streamlit.

## 🚀 Features

- Upload Resume (PDF)
- Extract Resume Text
- Generate AI Interview Questions
- Evaluate Candidate Answers
- Calculate Interview Score
- Generate Downloadable PDF Report

---

## 🛠 Technologies Used

- Python
- Streamlit
- PDFPlumber
- ReportLab

---

## 📂 Project Structure

```bash
AI-Mock-Interviewer/
│
├── app.py
├── requirements.txt
├── README.md
│
├── utils/
│   ├── resume_parser.py
│   ├── question_generator.py
│   ├── answer_evaluator.py
│   └── report_generator.py
```

---

## ▶️ Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

---

## 💡 Workflow

1. Upload Resume
2. Extract Resume Content
3. Generate Interview Questions
4. Answer Questions
5. Receive Evaluation & Score
6. Download Interview Report
